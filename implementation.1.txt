# 3. Use a notification table

The easiest way to make this reliable is to give SafeBrgy a central notification table.

For example:

```sql
CREATE TABLE notifications (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,

    user_id INT UNSIGNED NOT NULL,

    type VARCHAR(50) NOT NULL,
    title VARCHAR(150) NOT NULL,
    message VARCHAR(500) NOT NULL,

    target_url VARCHAR(255) DEFAULT NULL,

    is_read TINYINT(1) NOT NULL DEFAULT 0,

    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,

    INDEX idx_notifications_user_read (user_id, is_read),
    INDEX idx_notifications_user_id (user_id, id),

    CONSTRAINT fk_notifications_user
        FOREIGN KEY (user_id)
        REFERENCES users(id)
        ON DELETE CASCADE
);
```

Your existing `users` table may use a different primary-key type. If so, change:

```sql
INT UNSIGNED
```

to match your actual `users.id`.

# 5. `api/fetch.php` should NOT return HTML

Make it a JSON API.

For example:

```php
<?php

declare(strict_types=1);

require_once __DIR__ . '/../config/db.php';

if (session_status() !== PHP_SESSION_ACTIVE) {
    session_start();
}

header('Content-Type: application/json; charset=utf-8');

if (empty($_SESSION['user_id'])) {
    http_response_code(401);

    echo json_encode([
        'success' => false,
        'error' => 'Authentication required.'
    ]);

    exit;
}

$userId = (int) $_SESSION['user_id'];

$database = db();

$lastId = max(
    0,
    (int) ($_GET['last_id'] ?? 0)
);

$statement = $database->prepare(
    'SELECT
        id,
        type,
        title,
        message,
        target_url,
        is_read,
        created_at
     FROM notifications
     WHERE user_id = :user_id
       AND id > :last_id
     ORDER BY id ASC
     LIMIT 50'
);

$statement->execute([
    'user_id' => $userId,
    'last_id' => $lastId
]);

$notifications = $statement->fetchAll(PDO::FETCH_ASSOC);

$unreadStatement = $database->prepare(
    'SELECT COUNT(*)
     FROM notifications
     WHERE user_id = :user_id
       AND is_read = 0'
);

$unreadStatement->execute([
    'user_id' => $userId
]);

$unreadCount = (int) $unreadStatement->fetchColumn();

echo json_encode([
    'success' => true,
    'notifications' => $notifications,
    'unread_count' => $unreadCount,
    'server_time' => date('Y-m-d H:i:s')
]);
```

This is the basic engine.

# 6. Why `last_id` is important

Suppose the browser has already received:

```text

Notification 101
Notification 102
```

JavaScript remembers:

```javascript
lastNotificationId = 102;
```

The next request becomes:

```text
/api/fetch.php?last_id=102
```

The database only needs to return:

```text
103
104
105
```

instead of returning the entire notification history every time.

This is the same concept as the `after_id` in your GamersHUB messaging API.

# 7. Background JavaScript

Create:

```text
assets/js/realtime.js
```

Use:

```javascript
(() => {
    let lastNotificationId = 0;
    let polling = false;

    async function checkUpdates() {
        if (polling) {
            return;
        }

        polling = true;

        try {
            const response = await fetch(
                `/safebrgy/api/fetch.php?last_id=${lastNotificationId}`,
                {
                    method: 'GET',
                    credentials: 'same-origin',
                    cache: 'no-store',
                    headers: {
                        'X-Requested-With': 'XMLHttpRequest'
                    }
                }
            );

            if (!response.ok) {
                return;
            }

            const data = await response.json();

            if (!data.success) {
                return;
            }

            if (Array.isArray(data.notifications)) {
                for (const notification of data.notifications) {
                    handleNotification(notification);

                    const id = Number(notification.id);

                    if (id > lastNotificationId) {
                        lastNotificationId = id;
                    }
                }
            }

            updateNavigationBadge(data.unread_count);

        } catch (error) {
            console.error('SafeBrgy realtime error:', error);
        } finally {
            polling = false;
        }
    }

    function handleNotification(notification) {
        showNotification(notification);
    }

    function updateNavigationBadge(count) {
        const badges = document.querySelectorAll(
            '[data-notification-badge]'
        );

        badges.forEach(badge => {
            const value = Number(count);

            if (value > 0) {
                badge.textContent = value > 99 ? '99+' : value;
                badge.classList.remove('d-none');
            } else {
                badge.textContent = '';
                badge.classList.add('d-none');
            }
        });
    }

    function showNotification(notification) {
        if (typeof window.showSafeBrgyNotification === 'function') {
            window.showSafeBrgyNotification(notification);
        }
    }

    async function initialize() {
        try {
            const response = await fetch(
                `/safebrgy/api/fetch.php?last_id=0`,
                {
                    credentials: 'same-origin',
                    cache: 'no-store'
                }
            );

            const data = await response.json();

            if (data.success) {

                /*
                 * Initial load should NOT display old
                 * notifications as new popups.
                 */
                if (Array.isArray(data.notifications) &&
                    data.notifications.length > 0) {

                    lastNotificationId =
                        Number(
                            data.notifications[
                                data.notifications.length - 1
                            ].id
                        );
                }

                updateNavigationBadge(data.unread_count);
            }

        } catch (error) {
            console.error(error);
        }

        checkUpdates();

        setInterval(checkUpdates, 3000);
    }

    document.addEventListener('DOMContentLoaded', initialize);
})();
```

Change:

```javascript
/safebrgy/api/fetch.php
```

to whatever your actual SafeBrgy URL is.

        ↓

        ↓

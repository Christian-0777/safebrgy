What's New

A guide to improvements across the SafeBrgy resident portal and administration services, from the latest release to the original launch.

Release history · Latest version: V4.1

V4 releases

V4.1 · Real-time notifications

Notifications now connect to the relevant report, service request, or announcement. Residents and administrators can see unread indicators alongside records, and viewing an item clears its notification. Lists refresh automatically to keep recent activity visible, while notification counts remain consistent across navigation.

Announcement details now mark an item as read when opened. Notification identity is also matched to the active account role, keeping resident and administrator alerts separate.

V4.0 · Report management

Residents can submit reports with relevant categories, tags, and a required location, and can browse community reports where available. Report details include expiration information and clearer status indicators.

Administrators can filter reports by type and tag, update multiple statuses together, and review or export records for a selected date range. Reports have a 15-day pending period; moving a report into progress restarts that period.

V3 releases

V3.5 · Background notifications

Added background alerts for new reports, requests, announcements, and status changes, with navigation badges and in-page notifications. Alerts update without interrupting normal page activity.

V3.4 · Account and verification improvements

Profile photo changes now save with account updates and remain visible when returning to the profile. Registration email verification was improved to handle code expiry consistently and provide clearer guidance when information or uploads need attention.

V3.3 · Request rejection workflow

Administrators now confirm a rejection and select a reason before a resident is notified. The rejection details can include additional instructions, making request outcomes clearer to applicants.

V3.2 · Deployment and access updates

Updated access paths for resident and administrator landing pages and improved search-engine handling for administrator pages.

V3.1 · Remember Me sign-in

Residents and administrators can stay signed in between visits by choosing Remember Me. Persistent sign-in is time-limited, protected, and revoked when the user logs out.

V3.0 · Resident registration

Introduced a guided resident registration process with identity and profile uploads, an information review, email verification, and password recovery. New accounts enter the existing approval process after registration.

V2 releases

V2.6 · Profiles and administrator settings

Resident profiles gained saved cover photos and improved image handling. Administrators gained a centralized settings area for account details, barangay information, security options, and operational logs.

V2.5 · Shared interface improvements

Introduced a consistent layout and navigation across resident and administrator pages, with improved spacing, forms, tables, and mobile navigation.

V2.4 · Cleaner page addresses

Added shorter, cleaner addresses for commonly used resident and administrator pages while preserving existing sign-in and form workflows.

V2.3.1 · Sign-in experience

Refreshed the resident and administrator authentication pages with a unified visual design.

V2.3 · Dashboard layout

Adjusted the dashboard card layout to create a more balanced presentation across screen sizes.

V2.2.7.1 · Email updates

Residents can receive email updates about request and report status changes, as well as newly published announcements.

V2.2.6 · Resident service requests

Introduced a resident request portal for barangay documents, including guided request forms, submission tracking, and supporting document uploads.

V2.2.5 · Resident account settings

Added a central account area for personal and contact information, security, notification preferences, privacy requests, support, and account actions.

V2.2.4 · Resident profile

Added a profile overview with personal and contact information, verification status, identification preview, and recent service request history.

V2.2.3 · Resident identification

Residents began receiving a unique identification number during registration to support account and service identification.

V2.2.2 · Administrator profile

Added an administrator profile with account details, operational statistics, recent activity, and information export.

V2.2.1 · Verification overview

Added a summary of pending, verified, and rejected accounts to the administrator verification page.

V2.2 · Guided document requests

Expanded resident document requests with forms tailored to each service, request history, submission references, and supporting document uploads. Administrators can review applicant and request details while managing request status.

V2.1 · Administrator dashboard

Added an operational overview with resident and service metrics, demographic summaries, recent activity, pending items, and upcoming events.

V2.0 · Resident request workflow

Introduced a guided, multi-step process for requesting barangay documents, with request references, status history, and an expanded administrator review experience.

V1 releases

V1.9 · Resident reports

Residents can submit and track incident, lost property, and blotter reports, including optional images, status summaries, and report details.

V1.8 · Resident announcements

Added searchable and sortable announcement listings with priority information and a detailed announcement view.

V1.7 · Resident dashboard

Expanded the resident dashboard with service shortcuts, request and report summaries, recent announcements, and activity updates.

V1.6 · Administrator request management

Added request search and filtering, processing summaries, detailed request review, and status management for administrators.

V1.5 · Administrator report management

Added report search, case tracking, status summaries, and detailed review and status management for administrators.

V1.4 · Administrator announcements

Added tools for administrators to create, schedule, prioritize, organize, and manage resident announcements.

V1.3 · Resident registration and approval

Introduced resident registration and sign-in, with new accounts awaiting administrator review before activation.

V1.2 · Administrator authentication

Added administrator registration and sign-in with email verification, protected pages, and password recovery.

V1.1 · Administrator registration

Introduced an administrator account registration form with password and contact information checks.

V1.0 · Initial release

Launched the core SafeBrgy portal for resident access and barangay administration, including announcements, reports, service requests, account management, and administrator tools.
